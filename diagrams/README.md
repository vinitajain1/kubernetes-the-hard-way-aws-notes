# Diagrams

`kthw-aws.drawio` has two pages:

1. **Network:** VPC, subnet, security group, internet gateway, route table and the four instances.
2. **Certificates (PKI):** each component, its certificate and identity, and the six connections labelled mTLS, TLS + token or plain HTTP.

Open it at [app.diagrams.net](https://app.diagrams.net) with **File → Open from → Device**. To export images, use **File → Export as → PNG** (200% zoom) or **PDF** (all pages).

The README also has Mermaid versions of both diagrams, which GitHub renders directly.
